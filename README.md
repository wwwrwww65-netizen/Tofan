## 1. نظرة عامة على النظام ومسار العمل

تم بناء هذا المشروع ليعمل كـ **Single Page Application (SPA)** عالي السرعة والأداء ومتوافق بنسبة 100% مع معايير مشروع **`Tofan`** القياسية لراوترات المايكروتك.

### 🔄 دورة حياة الاتصال:
```text
[المستخدم يتصل بالشبكة] ──> تفتح نافذة تسجيل الدخول التلقائية
                                    │
                                    ▼
                 إرسال فحص الحالة الأولي من الروتر:
                 GET /login?var=callBack
                                    │
                  ┌─────────────────┴─────────────────┐
                  ▼                                   ▼
        [المستخدم مسجل مسبقاً]              [المستخدم غير مسجل]
                  │                                   │
                  ▼                                   ▼
      يستجيب المايكروتك عبر:             فحص الكوكيز المحفوظة عبر:
         alogin.html                       cookieLogin()
      استدعاء: onLoggedIn(e)                          │
      الانتقال الفوري لشاشة الحالة        ┌───────────┴───────────┐
      وبدء الاستعلام كل 1 ثانية           ▼                       ▼
                                   [يوجد كرت سابق]         [لا يوجد كرت]
                                          │                       │
                                          ▼                       ▼
                                تسجيل الدخول التلقائي     البقاء في شاشة الدخول
                                عبر: getRequest(...)     وانتظار إدخال الكرت
```

## 2. آلية وطريقة إرسال الطلبات إلى المايكروتك (MikroTik Request Architecture)

تعتمد البوابة على إرسال طلبات `XMLHttpRequest` غير متزامنة (AJAX) بصيغة خفيفة ومباشرة لروتر المايكروتك:

### 1) دالة إرسال الطلبات العامة (`getRequest`):
```javascript
function getRequest(e) {
  var t = new XMLHttpRequest();
  t.open("GET", e, !0);
  t.onreadystatechange = function () {
    if (4 === this.readyState && 200 <= this.status && 400 > this.status) {
      var n = JSON.parse(this.responseText);
      if (n && n.action && typeof window[n.action] === "function") {
        window[n.action](n);
      }
    }
  };
  t.send();
  t = null;
}
```

### 2) دالة تسجيل الدخول اليدوي (`userLogin` & `Ulogin`):
عند نقر المستخدم على زر **"تسجيل الدخول"** أو الضغط على زر **Enter**، يتم تجميع رمز الكرت، السرعة المختارة، وحالة مفتاح إيقاف التحديثات، ثم إرسال الطلب بالصيغة المعتمدة:
```javascript
function userLogin() {
  var speedVal = document.getElementById("speed").value; // مثل "128K/512K"
  var isBlockUpdates = document.getElementById("chupdate").checked; // مفعل أو متوقف
  var domainParam = (speedVal ? speedVal : "") + (isBlockUpdates ? "_Uoff" : "");
  var baseCard = document.login.username.value.trim();
  var pass = document.login.password ? document.login.password.value : "";

  // حفظ في الكوكي والذاكرة المحلية
  setLoginCardCookie(baseCard, pass, domainParam);
  
  // إرسال الطلب الفعلي للمايكروتك
  Ulogin(baseCard, pass, domainParam);
}

function Ulogin(e, t, n) {
  var domVal = (n !== undefined && n !== null) ? n : "";
  var url = "/login?username=" + e + "&password=" + t + "&domain=" + domVal + "&var=callBack";
  getRequest(url);
}
```

## 3. نظام تحديد السرعات وتمرير معامل الدومين (Speed Selection & Domain Parameter)

يتم التحكم بسرعة الكرت مباشرة عبر متغير `domain` الذي يستقبله راوتر المايكروتك في سكربت `on-login` الخاص بالـ Hotspot User Profile:

| خيار السرعة | القيمة المرسلة في `domain` | التأثير في المايكروتك |
| :--- | :--- | :--- |
| **سرعة افتراضية** | `""` (فارغ) | تطبيق السرعة الافتراضية المحددة في بروفايل الكرت |
| **سرعة منخفضة 512** | `128K/512K` | تحديد معدل النقل (Rate-Limit) إلى 128k رفع / 512k تنزيل |
| **سرعة عادية 1 ميجا** | `256K/1024K` | تحديد معدل النقل إلى 256k رفع / 1024k تنزيل |
| **سرعة متوسطة 2 ميجا** | `512K/2048K` | تحديد معدل النقل إلى 512k رفع / 2048k تنزيل |
| **سرعة مفتوحة** | `1024K/4096K` | تحديد معدل النقل إلى 1M رفع / 4M تنزيل |

### ⚡ تغيير السرعة أثناء الاتصال من شاشة الحالة:
عند اختيار سرعة جديدة من شاشة الحالة:
1. يتم إرسال طلب خروج صامت `/logout?var=callBack`.
2. بعد تأكيد الخروج (100ms)، يتم إرسال طلب دخول فوري بنفس الكرت ومعامل السرعة الجديد.
3. يتم تحديث واجهة المستخدم والشاشات بدون الحاجة لإعادة كتابة الكرت.

## 4. ميزة إيقاف التحديثات والمتجر (Updates & App Store Blocker)

- **الهدف**: حماية رصيد باقة الكرت من الاستهلاك السريع في الخلفية بواسطة تحديثات نظام التشغيل ومتجر التطبيقات.
- **آلية العمل**:
  - في الوضع الطبيعي: يرسل المتغير فارغاً `""`.
  - عند التفعيل: يُدمج الرمز `_Uoff` مع معامل السرعة (مثال: `128K/512K_Uoff` أو `_Uoff`).
- **معالجة المايكروتك**: يتعرف راوتر المايكروتك عبر سكربت الهوتسبوت على وجود `_Uoff` ويقوم بإضافة عنوان IP الخاص بالمستخدم إلى قائمة العناوين المحظورة للتحديثات (`Updates-Block-List`) في الفايروول.

## 5. سرعة الاستجابة ودورة الإغلاق التلقائي للنافذة (Captive Portal Auto-Close)

### ⚡ زمن التنفيذ:
تتم المعالجة بالكامل في **أجزاء من الثانية (5 إلى 25 ميلي ثانية)** لأن الطلب يتم محلياً (Local Network Handshake) عبر معالج الروتر دون أي اتصالات خارجية.

### 🚪 آلية إغلاق النافذة التلقائي في أندرويد وآيفون:
1. بمجرد أن يرسل المتصفح طلب الدخول الناجح، يرد المايكروتك بملف `alogin.html` ويفتح مسار الإنترنت للـ MAC Address الخاص بالجهاز.
2. تتحول حالة الجلسة إلى `loggedIn = true` ويتم الانتقال لشاشة الحالة `#status`.
3. يتعرف نظام التشغيل (Android CaptivePortalLogin أو iOS CNA) فوراً على توفر الإنترنت ويقوم **بإغلاق النافذة المنبثقة تلقائياً** ليتمكن المستخدم من تصفح تطبيقاته بحرية.

## 6. نظام الحفظ التلقائي والكوكيز (`hotCookie.min.js`)

- **حفظ بيانات الجلسة (`setLoginCardCookie`)**: يتم تخزين رقم الكرت، كلمة المرور، ومعامل السرعة والتحديثات في كوكيز المتصفح والذاكرة المحلية `localStorage`.
- **استرجاع الكروت السابقة (`getStoredValuesFromCookie`)**: تخزين آخر الكروت المستخدمة لإتاحة الدخول بكرت سابق بنقرة زر واحدة عبر زر "دخول بكرت سابق" أو القائمة المنسدلة `#se`.
- **تسجيل الخروج ومسح الكوكيز (`clearCookies`)**: عند ضغط المستخدم على زر "تسجيل الخروج" أو "قطع الاتصال"، يتم مسح الكوكيز لضمان عدم الاتصال التلقائي غير المرغوب فيه.

---

## 7. معالجة الأخطاء والترجمة الفورية (`onLoginError`)

عند إدخال كرت غير صحيح أو منتهي أو مستخدم في جهاز آخر، يستجيب المايكروتك بقالب `login.html` متضمناً كود الخطأ:
- **`onLoginError(e)`**:
  - تمنع الانتقال لصفحة الحالة وتُبقي المستخدم في صفحة تسجيل الدخول.
  - تستدعي دالة `toArabicError` لترجمة الخطأ فورياً إلى رسالة عربية واضحة ومفهومة.
  - تعرض التنبيه المنبثق الأنيق `showErrorPopup()` فور وصول الرد.
  - تقوم بتشغيل عداد حظر التخمين `hotBlocker` في حال تكرار المحاولات الخاطئة.

## 9. دليل الرفع والتثبيت على راوتر المايكروتك

1. **نسخ الملفات**: قم بنسخ جميع ملفات ومجلدات المشروع إلى مجلد الهوتسبوت في المايكروتك عبر برنامج **WinBox** (القائمة `Files`).
2. **إعداد بروفايل الهوتسبوت**:
   - اذهب إلى: `IP` -> `Hotspot` -> `Server Profiles`.
   - افتح بروفايل الهوتسبوت الخاص بك.
   - اضبط **HTML Directory** على اسم المجلد المرفوع.
   - في تبويب **Login**، فعّل كلاً من: `HTTP PAP` و `HTTP CHAP` و `Cookie`.
3. **التشغيل**: اتصل بالشبكة من أي هاتف أو كمبيوتر لتفتح صفحة تسجيل الدخول فوراً وبأعلى أداء.
